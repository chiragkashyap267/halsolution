# HAL Solution

HTML, CSS, and JavaScript website for HAL Solution. Open `index.html` in a browser to preview. No dependency installation or build step is required.

## Hostinger deployment

Connect this repository to a custom PHP/HTML website using **Advanced → Git**. Deploy the `main` branch to `public_html`. Website files, including `index.html` and `images/`, are at the repository root.

Edit the root website files for future changes. The original ZIP files and extracted reference folder are excluded from Git.

## Functionality

The current website is a frontend prototype. OTP authentication, persistent bookings, callback delivery, and protected admin access require backend integration. Current dashboard content is sample data, and location handling still includes a placeholder address.
